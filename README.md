# 登神 · 从 LDL 打上来

一个英雄联盟职业生涯文字模拟游戏。**三年，从 LDL 打到世界赛。** 也可以在**无尽生涯**里一直打到自己按停止键。

双击 `index.html` 就能玩，纯前端、零依赖、不需要联网，也不需要起服务器。

---

## 一、怎么玩

1. 双击 `index.html`（推荐 Chrome / Edge）。
2. 主菜单 → **开始职业生涯** → 选模式（三年之约 / 无尽生涯）与难度。
3. 起一个 ID（就是解说会喊的那个名字），从三组基底里挑一组，选位置、选英雄池、选出身。
4. 之后按月推进，一年十二个月就是一个完整赛季：**每个月 1 个行动 → 当月赛程 → 可能一个事件 → 月末结算**。
   - 1 月常规赛 → 2 月第一赛段季后赛 → 3 月**先锋赛**（赛段前二去）
   - 4 月常规赛 → 5 月第二赛段季后赛 → 6 月**MSI**（赛段前二去）
   - 7 月常规赛 → 8 月第三赛段季后赛 → 9 月世界赛瑞士轮 → 10 月八强/四强/决赛
   - 11 月全明星与年度颁奖 → 12 月转会窗
5. 三年（36 个月）走完出结局：档位 + 三年时间线 + 赛季回顾。

**操作**：全程鼠标点按钮；也可以按数字键 `1`–`9` 选选项，`Enter` 继续。
底部常驻条可以随时 **存档 / 读档 / 看档案**，还能关掉 **弹幕** 和 **声音**。存档在浏览器本地，共 1 个自动档 + 3 个手动档。

**一局大约 23–30 分钟**（约 400 个界面，其中一半是比分和结算，不用读字）。

### 两种模式

| 模式 | 规则 |
|---|---|
| **三年之约** | 36 个月打完出结局。标准体验，一场完整的三年青春。 |
| **无尽生涯** | 没有终点。第 4 季起联赛水平每年抬高，26 岁后成长腰斩、32 岁后每年掉属性，33 岁强制退役。每年 12 月可以自己决定「再打一年」或「在这里结束」，没人报价时也会坐到那个位置上。结局按打到的季数、冠军数、OVR 和退役方式另写。 |

无尽模式独有 13 条老将线事件（青训小孩请教你、手腕旧伤、直播七位数合同、版本砍你的绝活、体检报告、老粉的票根……）。

## 二、你要做的决策，每类只有一个

| 层级 | 你决定什么 | 频率 |
|---|---|---|
| 建档 | ID、基底、位置、英雄池、出身 | 开局一次 |
| 月度 | 1 个行动：加练 / 复盘 / 排位 / 开播 / 休息 / 健身 / 找教练 / 心理辅导 / 给管理层施压 | 每月 |
| 事件 | 2–3 个选项，可能要过判定 | 约七成月份 |
| 对局 | 情境卡 2–3 选 1，可点「爆种」；常规赛自动打，季后赛/世界赛逐局打 | 关键比赛 |
| 抽卡 | 抽天赋 / 技能 / 特质 / 道具，10 抽保底紫 | 随机 + 年末 |
| 转会 | 接受报价 / 留队；LDL 打出来才有 LPL 的票 | 每年 12 月 |

**爆种**：气势攒到 60，对局里能把一次判定直接拉成成功（代价是精力和 10% 受伤风险）。气势靠赢团、赢局涨，输就掉。

## 三、数值怎么长

八维：**对线 LANE / 操作 MECH / 意识 GAME / 英雄池 POOL / 心态 MENTAL / 体能 PHYS / 名气 FAME / 团队 TEAM**，各 0–100。

- OVR 按位置加权（中单吃 MECH+GAME，辅助吃 GAME+TEAM，ADC 吃 LANE+MECH）。
- 月成长 = 训练量 × 年龄系数 × 潜力剩余 × 状态 × 随机（0.75–1.35）。三年成长总量被刻意压住：**第一年就是 LDL 水平，别想一步登天**。
- 精力低于 16 会按伤病倾向判定受伤；伤病掉体能、掉状态。
- 队伍强度 = 五位置 OVR 加权 + 化学反应 + 教练系数 + 版本适配；你的 OVR 在自己队里权重 1.35。

## 四、赛制（写实，三段赛）

一个赛季分三个赛段，每个赛段都是「一个月常规赛 + 一个月季后赛」，季后赛决出赛段名次（第 1 到第 10）。

- **第一赛段**：常规赛 5 场 BO3，前 10（LDL 前 6）进季后赛，BO5 三轮。**赛段前二 → 先锋赛**。
- **第二赛段**：同上。**赛段前二 → MSI**。
- **第三赛段**：同上。**赛段前四 → 全球总决赛**（这一条是硬门槛，没有积分兜底）。
- **先锋赛 / MSI**：半决赛 → 决赛两场 BO5，对手是 T1、GEN、G2、FNC 这些外赛区队伍。
- **世界赛**：瑞士轮 5 轮（3 胜出线 / 3 负回家），八强、四强、决赛 BO5，对手强度逐轮抬。
- **升降级**：按现实规则——LPL 已联盟化，**不搞直接降级**。从 LDL 上去的路是：LDL 赛段夺冠 → 年末 LPL 战队报价（LDL 冠军保底一张门票）。LPL 垫底不会掉级，但会掉赞助、掉人。
- 2024 年及之前的战绩、冠军、对阵全部按真实历史写；**2025 年起的赛果是推演**（游戏从 2025 年 1 月开始）。档案室里有编年史可查。

**真实选手 ID，梗正负都来**。夸的时候是真夸，骂的时候也不留情面——但只对事不对人：卡面和事件里的调侃都是公开梗，不是对选手的事实指控。这一点主菜单底部也写了一句。

**比赛里有弹幕**。打季后赛、世界赛的时候，屏幕左侧会自动飘弹幕：僵尸、水鬼、碧螺春、猪仔、皇杂、60E、韩杂、黑子、串子、路人各说各的，自己队打得好也骂、打得烂也骂。底部常驻条可以关掉。

### 声音

全部是 **Web Audio 现场合成**，没有一个音频文件，离线、双击即响。第一次点击之后才出声（浏览器规矩）。

- **BGM** 七套循环：主菜单（慢、空）、LDL（粗糙小场馆）、LPL（联赛进行曲）、季后赛（十六分脉冲、军鼓）、世界赛（大编制、定音鼓）、夺冠（大调号角）、结局（钢琴琶音）。切场景自动淡入淡出。
- **音效** 二十个：点击、翻卡、出紫出金、出赤、骰子、赢局、输局、击杀、大龙、推塔、欢呼、嘘声、夺冠、被淘汰、签约、退役、成长、热搜提示。
- 旋律全是原创的，没有引用任何真实赛事主题曲。

## 七、改内容

- **加事件**：照 `js/data/events.js` 的结构往数组里塞，`req.stage` 限定 LDL/LPL，`year` 限定年份，`once` 只触发一次。
- **加开局基底**：照 `js/data/bases2.js`，写成 `window.DATA_BASES_EXTRA = [...]`，字段和 `engine.js` 里 `BASES` 一致，引擎会自动合并。
- **加弹幕**：照 `js/data/danmaku.js`，十个分类 + `groups` 粉籍表，`{t,g}` 两个字段，`{name}/{team}/{opp}/{pos}/{score}` 会被替换。
- **加天赋卡**：照 `js/data/talents.js`，`eff` 里放属性增减；`special` 目前接了这些钩子：`diceRoll / godMode / lastDance / jungleKing / glassBody / stealWin / pause / trashTalk`，在 `engine.js` 的 `resolveDuel`、`gain`、`monthEnd` 里生效。
- **跑自测**（需要 node）：
  ```
  node tools/qa2.cjs three       # 三年模式跑两局，检查渲染和报错
  node tools/qa2.cjs endless     # 无尽模式跑到主动退役
  node tools/stats.cjs 20 hard   # 20 局 hard 的结局与数值分布
  node tools/probe.cjs three normal 20250101   # 单局打印赛段名次/国际赛/时间线
  ```

## 八、已知边界

- 2025 年之后没有真实历史可依，所以从 2025 起的战绩是模拟推演；真实数据截至 2024 赛季。
- 选手中文名未知的留空显示 ID，不臆造。
- 世界赛只做瑞士轮 + 三场淘汰赛，不做入围赛细节；先锋赛与 MSI 只做半决赛 + 决赛两场 BO5，不做小组赛与双败。
- 第三赛段的前四直接进世界赛（写实赛制里还有积分与席位分配，这里为了节奏做了简化）。
- 结局判定看重冠军、世界赛最佳成绩、OVR、名气，共 9 档；无尽模式另有按季数、退役方式的文本。
- 无尽模式的后期靠「对手逐年变强 + 26 岁后成长衰减 + 32 岁后属性下滑」压住，不靠削你的数值。三十岁之后每一年都更难，这是设计意图。
- 音乐音效是程序合成的，听感是「电子 + 管弦」的氛围，不是真录音；嫌吵可以一键静音，静音状态会记住。
